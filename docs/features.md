# 原型與 Windows 公開版功能對照表

「✓」代表公開原始碼有這項功能。「另設」代表程式已提供，使用者須在自己的電腦準備帳號、硬體、服務或權限。「—」代表公開版未附該項實作。這三種標記描述發行內容；你的電腦是否已經設定或實測，需依最後一欄核對。

首次開啟或在「設定 → 元件」可選取這台電腦要用的核心、自架模型、語音、電腦操作、外部服務及手機元件。新對話、工作區、搜尋與排程直接提供。

表中也保留私人原型做過的事。舉例來說，若你的目的是「快用完額度時提醒我」，可以請自己的 AI 用目前帳號的官方額度和查詢時間設計提醒。供應商若只提供重設時間，就提醒下次何時查看，剩餘百分比顯示「未知」。往後有新的官方介面，也能在自己的分支接上並測試。

## 核心、登入與額度

| 原型功能 | 公開版 | 怎麼啟用或確認 |
| --- | --- | --- |
| Codex CLI | 另設 | 在「設定 → 帳號與核心」安裝核心，以自己的訂閱登入。開 Codex 聊天室，送出訊息確認。 |
| Claude Code | 另設 | 使用 Claude Code 官方登入。確認登入狀態後，開 Claude 聊天室測試。 |
| Gemini／Antigravity | 另設 | 安裝 Antigravity，在 K 開啟官方登入，由本人完成驗證。可依目前帳號的模型清單開房。 |
| Grok Build | 另設 | 安裝 Grok 核心並以自己的訂閱登入。在 Grok 聊天室測試。 |
| DeepSeek Harness | 另設 | 核心下載支援 Windows x64，需先安裝 7-Zip。在「API 連線」設定自己的 DeepSeek 金鑰。主對話與工人都由該 API 帳戶計費。 |
| 模型、推理程度、權限與核准 | ✓ | 在聊天室檢查該核心提供的選項。Codex Fast 須由該核心列出可用層級；各家可選權限不同。 |
| 訂閱剩餘額度、重設時間 | 另設 | 登入後開啟額度頁。數字依供應商回報，欄位缺少或查詢失敗時查看狀態與時間。Gemini 查目前登入帳號的官方 `/usage`。 |
| 估補 Grok 未回報的週額度 | — | 原型有自己的顯示規則。公開版只顯示有來源的百分比；若官方只有重設時間，就只列時間。可在自己的分支設計提醒或另行標示估算。 |
| DeepSeek 餘額、房間花費估算 | 另設 | 餘額來自該帳戶的官方 API，房間估算使用原生用量與公開價格。以供應商帳單確認實際費用。 |
| 原型的 Gemini 多帳號即時額度、一鍵切換與借用歸還 | — | 私人原型另有管理方式。公開版由本人使用官方登入切換。想設計自己的帳號提醒，可從額度的查詢時間、重設時間和官方登入狀態開始。[官方登入與登出](https://antigravity.google/docs/cli/install/) |
| 核心下載、更新、工作台更新 | ✓ | 在 Windows 設定頁操作核心更新。更新會說明目前與下次啟動版本，並略過已知有問題的版本。Antigravity 更新後、重新開啟前先做權限驗證。[更新說明](windows-install.md#核心相容性與更新) |

## 工作台與協作

| 原型功能 | 公開版 | 怎麼使用或確認 |
| --- | --- | --- |
| 選擇元件（公開版新增） | ✓ | 首次開啟或在「設定 → 元件」選取，重新開啟 K 核對。 |
| 工作區、專案側欄、搜尋、釘選與排序 | ✓ | 選擇自己的資料夾，建立聊天室，再重開工作台確認清單。手動排序時可從選單「移到指定位置」直接調整同組順序。 |
| 聊天室搜尋與工作區檔案搜尋 | ✓ | 前者依對話標題、工作區或模型尋找；後者在支援的核心依檔名尋找工作區檔案。 |
| 顯示主題、閱讀外觀與後續訊息偏好 | ✓ | 從設定選淺色、暖色或深色，調整閱讀外觀與工作中訊息的排隊或插話行為。 |
| 多聊天室同時工作、草稿、佇列、插話與停止 | ✓ | 切到另一房後回到原房查看進度。插話能力依核心；停止針對來源房間。 |
| 附件、回覆引用、檔案預覽與下載 | ✓ | 附上測試檔或選取文字引用。檔案種類依所用核心；可從右側檢視成果。 |
| 工具執行、原生變更差異、訊息複製 | ✓ | 在支援的核心展開工具或回合差異；可在訊息按複製。差異內容依核心實際回報。 |
| 對話分支、移到其他工作區與原生程式碼審查 | ✓ | 依核心選擇分支或審查。可支援的聊天室可從選單移到另一個已登記工作區；Grok 與 DeepSeek 已有原生對話時綁定原目錄，請在新工作區開新房。 |
| 通知、待處理問題、人工核准與背景工作 | ✓ | 側欄與來源房顯示尚未結束的背景工作，主回合閒置時可停止本房背景工作。更新遭阻擋時會列出房名與原因；待確認不會當作已完成。 |
| 子代理派工、提問、取消與完成回報 | 另設 | 先設定要用的核心。發一項小任務並查看工人明細；付費 API 諮詢需自備金鑰。 |
| 多模型討論 | 另設 | 在討論選擇器設定參與者並確認費用，由主持房啟動。選用外部搜尋時，查詢內容會送往搜尋服務。 |
| 持續目標、暫停與接續 | ✓ | 在支援的核心查看目標狀態。先核對中斷前的結果，再接續尚未完成的部分。 |
| 跨房留言、交接、建立新房與排程 | ✓ | 留言可在收件房讀取。交接會開新房。排程頁顯示執行時間與目標房。 |
| 原生對話脈絡、壓縮、核心記憶 | ✓ | 由各核心管理。跨核心交接時選擇要交付的內容。 |
| 個人共同偏好、跨核心工作規則 | 另設 | 在本次安裝的 `vault/private-state/agent-home/shared/` 下，以 `common-memory.md` 存自己的偏好、`global-rules.md` 存跨核心規則。[尋找安裝目錄](windows-install.md#如何核對這台電腦) |
| 封存與移除對話、程式退版 | ✓ | 依畫面動作處理自己的聊天室。程式退版範圍是工作台程式。 |
| 還原工作區檔案、還原到任意對話時間點 | — | 原型與公開版目前都未提供。需要檔案版本時可由自己的專案使用 Git。 |

## 語音、艾瑪與本機工具

| 原型功能 | 公開版 | 怎麼啟用或確認 |
| --- | --- | --- |
| 本機麥克風聽寫 | 另設 | 選取聽寫後顯示麥克風，完成設定後即可使用。移上去或點選可看設定提示。停止後預設留在草稿；電腦和手機都可明確選擇「轉錄完成後送出」，並保持送到來源房間。 |
| Windows 繁體中文語音辨識 | 另設 | 安裝 Windows 繁中語音辨識引擎並選擇 `windows`。[聽寫設定](../README.md#本機聽寫) |
| 離線 Whisper、CPU 或 NVIDIA 加速 | 另設 | 自備 Python、套件與模型，再選擇 `whisper`。NVIDIA 只影響加速。可指定自己的詞彙資料夾。 |
| 瀏覽器語音輸入 | 另設 | 使用有語音辨識能力的瀏覽器，依提示同意後試說一句，核對文字草稿。 |
| 語音秘書艾瑪通話 | 另設 | 在「API 連線」設定自己的 Gemini Live 金鑰，允許麥克風後撥話。通話會將語音，以及艾瑪讀取的聊天室與檔案內容送往 Gemini Live。 |
| 艾瑪查房、讀房、轉達訊息、代開聊天室 | 另設 | 通話中可詢問房間狀況，也可請她看某房最近幾則對話。要送出訊息或開房時，先聽取覆誦並口頭確認，再到目標房查看。 |
| 艾瑪聊天、工作區文字檔列出、找檔與閱讀 | 另設 | 撥話後可直接聊天，或請她列出資料夾、依檔名找檔、讀已登記工作區的文字檔。只讀不寫；K 的狀態、登入資料、`node_modules`、`.git`、疑似金鑰檔，以及圖片、PDF、錄音不讀。 |
| 艾瑪 Google 搜尋、工作區以外的唯讀資料夾 | 另設 | 預設關閉。在 K 私有狀態的 `.runtime/voice-emma.json` 寫 `"googleSearch": true` 開啟搜尋；搜尋在 Google 端執行，支援與費用依你的 Gemini API 方案。`readFolders` 填入自己要開放的資料夾名稱與完整路徑才可讀，只能讀、不能拿來開聊天室。[設定範例](windows-install.md#如何核對這台電腦) |
| 艾瑪筆記、秘書室紀錄、回報與費用 | 另設 | 在秘書室核對自己的通話、筆記、轉達及回報。費用頁顯示用量估算，實際金額依服務商。 |
| K 專用 Chrome、一般／無痕模式、右側瀏覽器狀態 | 另設 | 設定 K 瀏覽器助手與專用設定檔，需無痕時自行允許擴充功能。以測試頁確認連線。 |
| Windows 桌面控制 | 另設 | 自備相容 Windows-MCP、設定執行檔並選用對應權限。授權後會操作前景鍵盤、滑鼠和視窗。 |
| 自架模型、本機推論、Colab 工作環境 | 另設 | 自行指定模型與推論環境。Colab 需自己的 Google 授權、可用運算資源及費用設定。 |
| 自動彙整多帳號 Colab 運算單元 | — | 公開版可由本人在官方方案頁查看。若要延伸，可為自己設計用量紀錄或提醒，並保留資料來源及時間。[Colab 方案頁](https://colab.research.google.com/signup) |
| Google 商家 | 另設 | 自備授權與相容用戶端，綁定允許的工作區，可查帳號、據點、評論和貼文。 |
| Google 試算表 | 另設 | 附工具程式，需自行在專案註冊 MCP，可讀取及依指定範圍寫列。 |
| 手機遠端工作台、Android 配件 | 另設 | 主要程式在 Windows 執行。手機端需自己的 HTTPS 連線與登入；建置 Android 配件時填自己的服務網址。 |
| Android 通知、從通知回房、選取文字加入聊天與 App 更新 | 另設 | 建置並安裝自己的 Android 配件後，在手機測試通知與文字選取。更新由自己的 Windows 工作台供應。 |

## 請自己的 AI 協助

可以把這句話交給能讀取本機專案的 AI：

> 請對照這份表和我的 Windows 安裝，列出我選的功能有哪些已實測、哪些只有設定、哪些還缺條件。針對公開版未附的項目，先說明要達到的效果和可用的官方介面，給我一個可在自己分支實作及測試的方案。涉及帳號、費用或麥克風時，先讓我決定。

要延伸登入與額度，可從 [Gemini 官方登入接頭](../src/gemini-login.mjs) 和 [額度顯示](../frontend/usage.jsx) 開始。語音功能可分別查看 [艾瑪可執行的工作](../src/voice-secretary.mjs)、[秘書室](../frontend/secretary-page.jsx) 與 [本機聽寫](../src/local-dictation.mjs)。使用新來源時，可先以測試資料驗證已登入、未設定、查詢失敗三種情況。
