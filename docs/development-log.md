# 開發紀錄

## Windows 公開版

這是獨立的公開原始碼版本。五個核心各自沿用使用者選擇的登入及計費方式。工作台可在全新工作區、沒有核心的情況下開啟。本機聽寫、自架模型、語音服務與外部連線依個人設定啟用。[功能對照表](features.md)

- 安裝與啟動器使用本儲存庫的 Git 版本建置。安裝檔案位於該次安裝目錄之下，核心另外從供應商取得。
- 聽寫在取得麥克風之前檢查設定。未設定通話金鑰時，艾瑪會顯示需要的連線。Android 配件由使用者提供自己的服務網址。
- Antigravity 採官方登入，額度讀取目前帳號的 `/usage`。Colab 運算單元可從官方方案頁查看。
- 自動測試使用隔離資料。Windows 桌面程式、瀏覽器介面測試及真人帳號登入是不同的驗證項目。麥克風、離線模型速度與各家帳號可用性需在使用者自己的電腦確認。[Windows 安裝與核對步驟](windows-install.md)

### 首次安裝驗證

從固定 Git 版本匯出原始碼，在新的 Windows 目錄安裝相依套件，建置網頁、Chrome 擴充功能與 Windows 啟動器。2,371 項自動測試全數通過。Grok 取消測試會先等測試核心收到提示，再觸發取消，讓較慢的電腦也能測到同一個狀態。

另以空白工作區啟動實際後端，從 Chromium 開啟工作台。Gemini 帳號清單為空，本機聽寫與艾瑪均顯示尚未設定。點艾瑪按鈕會開啟設定，展開功能清單可看到語音秘書的條件。模擬通話測試另核對了設定完成前的麥克風與語音權杖請求次數，兩者皆為零。

五個 Windows 核心分別在隔離環境回報了執行檔版本。本次測試未進行真人帳號的模型對話、付費通話或實體麥克風收音。

### 公開版複查與修正

- 聽寫、艾瑪、首次安裝及授權文件經獨立原始碼複查。安裝器以 Windows 內建的 ZIP 支援保留中文檔名，在個別建置程序設定腳本執行原則。將本機模型設定為 `false` 或 `null` 時會保持關閉。
- Gemini 官方登入期間會擋下新的 Gemini 工作。切換帳號時會清除舊額度及重設時間，同時作廢尚在回傳的舊查詢。回歸測試使用兩組模擬額度，也測到登出後顯示未知的情況。
- Claude 新開高權限對話或在送出時提高權限，都需要明確確認。在空白設定下，實際的 Claude 執行檔可列出原生權限選項，工作台也會因未登入而拒絕開啟模型工作。
- Colab 工具會提供官方方案頁。公開介面的手機遠端路由依安裝中實際可用的功能開放。[功能對照表](features.md)

Claude 曾複查本機聽寫及隱私處理，Gemini 複查首次安裝與帳號介面並核對修正。其後依複查意見，把 `RemoteSigned` 限在六個啟動隨附 PowerShell 腳本的子程序。以 `Restricted` 作為上層程序原則實測，Windows 可執行隨附助手並在空白輸入處停止；未讀取帳號憑證。

64 項瀏覽器介面情境均在相同的發行程式上驗證通過。完整測試先通過 63 項，剩下的新對話選單測試改成等提供者按鈕出現後再量測，單獨重跑通過。私人 Git 歷史、帳號資料、對話、安裝快取與測試輸出均排除於發行檔案之外。

在 32 個邏輯處理器的 Windows 電腦上，安裝時同時啟動大量測試程序，曾導致本機連線與計時測試失敗。安裝驗證現在一次最多執行四個測試檔。這個上限只適用於自動測試。

### 首次開啟時選擇元件

新安裝可選 5 個核心及 10 個選用元件。工作區、聊天室、搜尋與排程直接提供。元件選擇適用於同一次安裝，之後可在「設定 → 元件」調整。既有安裝若有聊天室或側欄設定，升級時先沿用原有的完整介面。

Opus 5.5 設計選單分類、兩個步驟與介面文字，並參與程式複查與修正。修正涵蓋取消選取後的核心查詢、既有聊天室及小螢幕排版。既有聊天室仍可用原核心接續，在該房開分支或選新工人時只提供目前選取的核心。元件資料定義位於 `shared/components.mjs`，安裝設定由 `src/component-preferences.mjs` 保存，畫面入口為 `frontend/component-picker.jsx`。

在空白 Windows 工作目錄實際啟動 K，只勾 Gemini 後重新載入，帳號與核心設定只顯示 Gemini。瀏覽器測試也驗證首次全部未勾、稍後再選、360 與 412 像素寬度、Android 所需的手機遠端、重新啟動後保存選擇、額度頁和新對話只顯示 Gemini，以及在設定中加回聽寫。這些測試使用隔離資料。真人登入、實體收音及付費通話須在使用者自己的環境驗證。

程式版本 `3d4638d` 的 2,377 項自動測試全部通過。65 項瀏覽器情境在整批執行時通過 64 項。另一項發現重新載入時討論模式可能讀到上一個畫面狀態，已修正，並以桌面與手機的討論情境單獨重測通過。
