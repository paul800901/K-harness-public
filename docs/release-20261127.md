# 2026-11-27 公開版更新

本次將工作狀態、手機操作、聽寫及語音秘書的已驗證修正整合到獨立公開版。保留五核心、首次元件選擇、官方登入與使用者自行設定的功能邊界；不帶入私人儲存庫歷史、帳號、對話、詞庫或本機路徑。

## 行為與主要檔案

- 背景工作：聊天室與側欄顯示尚未結束的工作，停止只作用於來源聊天室；更新前顯示阻擋原因。未知程序狀態仍保留，不當成完成，也不重送工作。主要檔案：`src/conversation-controller.mjs`、`src/claude-controller.mjs`、`src/gemini-controller.mjs`、`src/desktop-controller.mjs`、`frontend/work-status.mjs`。
- 手機與側欄：Android 保留原生文字選取把手；側欄可直接移到指定位置。聽寫增加明確的送出箭頭，一般停止仍保留草稿；切房不會把內容送到另一房。主要檔案：`android/src/tw/k/harness/MainActivity.java`、`frontend/chat-messages.jsx`、`frontend/position-dialog.jsx`、`frontend/voice-composer.jsx`。Android 原始碼版本為 1.0.4。
- 回覆與推理設定：Gemini 以既有原生紀錄核對保留回覆的順序；不同聊天室及排隊訊息保留各自選定的推理程度，不因切換畫面互相覆蓋。主要檔案：`src/gemini-reply-order.mjs`、`src/input-queue.mjs`、`frontend/main.jsx`。
- 聽寫：調整語音尾端與長段落切分，弱語音重解碼不附帶偏置提示。個人詞庫只從使用者自行設定的位置讀取。主要檔案：`scripts/local-dictation.py`、`test/test_local_dictation_gpu.py`。
- 原生核心：修正 ACP 錯誤碼範圍與 DeepSeek 回合歸屬；Grok 使用原生 `--no-leader`。Grok、DeepSeek 已建立的原生對話不能直接改到另一個實體工作目錄。主要檔案：`src/acp-agent.mjs`、`src/grok-acp.mjs`、`src/dsh-controller.mjs`、`src/deepseek-billing.mjs`。
- 核心更新：內建略過已知不適用的 Antigravity 1.5.17，另可合併使用者自己的略過清單；顯示目前版本、下次啟動版本與退回目標。這個版本的權限問題依先前實機測試紀錄採用，本輪公開版驗證的是略過行為，沒有再做真人登入的權限測試。主要檔案：`src/core-updates.mjs`、`scripts/antigravity-permission-probe.mjs`。
- 艾瑪：可直接交談、查看最近聊天室訊息，以及列出、尋找、讀取工作區文字。額外資料夾與 Google 搜尋皆由使用者選擇，預設不開啟；保留元件及使用者金鑰檢查。文字讀取拒絕非 UTF-8、含 NUL 或 PDF 標記的內容，避免將二進位檔送進通話。主要檔案：`src/voice-secretary.mjs`、`src/voice-workspace-read.mjs`、`frontend/component-picker.jsx`。設定及資料送往 Gemini Live 的說明見 [Windows 安裝文件](windows-install.md)。
